# bert-next-sentence-prediction
Deep learning project leveraging BERT for Next Sentence Prediction (NSP). Fine‑tune on custom datasets to classify whether one sentence logically follows another. Ideal for downstream NLP tasks like question answering, dialogue systems, document coherence, and text mining.


🚀 Features
Pretrained BERT Backbone: Uses Hugging Face’s bert-base-uncased model for robust language representations.
Custom Fine‑tuning: Easily adapt to your own dataset for domain-specific NSP tasks.
Evaluation Metrics: Provides accuracy, precision, recall, and F1-score.
Inference Script: Quick CLI tool to predict sentence pairs.
